# Security and responsible disclosure

This is a public **source research mirror**, not a live service. Please do not attach proprietary footage, model checkpoints, customer information, tokens, private job logs or screenshots containing personal paths.

If you find a security flaw affecting local model execution, source-file integrity, symlink/path handling, GPU job ownership or final-output publication, use GitHub's private vulnerability-reporting feature if available. Otherwise, avoid posting exploitation details or secrets in public issues.

No code path should auto-download unpinned model weights or untrusted ComfyUI nodes, silently overwrite source media, bypass a user's GPU lock or publish an unchecked video as completed.
